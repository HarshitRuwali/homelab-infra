homelab-infra

Documentation for the stacks in this repository.

Monitoring Central Grafana, Prometheus, Loki and Alloy: what is collected, what the dashboards show, and what alerts on it. Fleet Automation The Ansible control plane at ansible/: collectors, package patching, container updates, host onboarding and provisioned alerting. Open Memory Self-hosted semantic memory: PostgreSQL and Qdrant behind a FastAPI service, with an MCP server for coding agents. S3 Backup Nightly off-site backup of Immich and Nextcloud to Amazon S3: restic for the databases, rclone for the photo originals, restores drilled monthly. AI Box Model Queue Serializes inference requests for a shared single-GPU LM Studio host without model-swap races or silent model fallback. Security Stack Wazuh, CrowdSec, AdGuard Home and Greenbone on four small guests, with Suricata and ntopng on the firewall. Open source throughout.
Source on GitHub. Every module has its own dedicated site; each directory also carries a README with a quick start.
